# Portfólio Pessoal

Um site de portfólio profissional moderno e responsivo, desenvolvido com HTML5, CSS3 e JavaScript vanilla.

## 🎨 Características

- ✨ Design moderno e responsivo
- 🎯 Navegação suave entre seções
- 📱 Totalmente adaptado para dispositivos móveis
- ♿ Acessível e semanticamente correto
- 🚀 Performance otimizada
- 🎭 Animações suaves na rolagem

## 📁 Estrutura do Projeto

```
mmn/
├── index.html      # Página principal
├── styles.css      # Estilos CSS
├── script.js       # Funcionalidades JavaScript
└── README.md       # Este arquivo
```

## 🚀 Como Usar

### Opção 1: Abrir localmente
1. Clone ou baixe este repositório
2. Abra o arquivo `index.html` em seu navegador favorito

### Opção 2: Com um servidor local
```bash
# Se você tem Python 3
python -m http.server 8000

# Se você tem Python 2
python -m SimpleHTTPServer 8000

# Se você tem Node.js com http-server instalado
http-server
```

Depois acesse `http://localhost:8000` (ou a porta indicada)

## 📝 Seções

### Navegação
- **Início**: Seção hero com chamada para ação
- **Sobre**: Informações sobre você e suas habilidades
- **Projetos**: Galeria de projetos recentes
- **Contato**: Formulário para entrar em contato

## 🎨 Customização

### Cores
Edite os gradientes e cores em `styles.css`:
- Cor primária: `#667eea`
- Cor secundária: `#764ba2`
- Cor de texto: `#333`

### Conteúdo
Edite o `index.html` para:
- Mudar seu nome e descrição
- Adicionar seus projetos reais
- Atualizar suas habilidades
- Personalizar o formulário de contato

### Projetos
Atualize a seção de projetos com:
1. Nomes dos seus projetos
2. Descrições adequadas
3. Links para seus repositórios ou demos

## 🔧 Funcionalidades JavaScript

### Scroll Suave
Todos os links de navegação possuem scroll suave para as seções correspondentes.

### Animações
Cards de habilidades e projetos aparecem com animação ao entrar na viewport.

### Validação de Formulário
O formulário de contato valida os dados antes de enviar.

## 📱 Responsividade

- 📱 Tablets (768px+)
- 💻 Desktops (1024px+)
